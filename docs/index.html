守岸人衍射

普攻接技能、强化重击攒协奏。准备切人前开解放铺星域，两位队友在域内依次用变奏升域。等主 C 打完再送守岸人变奏，下一轮解放转好后重新铺场。

琳奈衍射

01
主力队冷凝

绯雪、琳奈、千咲

琳奈补套后优先复测

绯雪主C琳奈副C / 协奏千咲辅助 / 生存
共享位提醒
  1. 01
    千咲起手，打完链锯和解放，满协奏切琳奈。
  2. 02
    琳奈打解放、满蓄重击、三跳和强化下落，然后延奏给绯雪。
  3. 03
    绯雪变奏后接第三段普攻、强化重击，再开第一段解放。形态内打两段技能、完整普攻一至五段。闪避进入居合，连续普攻打三次居合，接强化重击、长按解放收尾。
  4. 04
    回千咲开始下一轮。绯雪还缺能量时，在辅助阶段补协奏和命中，再接轴。
实战要点

看视频时，先学琳奈的下落怎么接绯雪变奏，再学绯雪开大后的三次居合。

02
主力队气动

卡提希娅、夏空、千咲

可直接出战

卡提希娅主C夏空副C / 协奏千咲辅助 / 生存
共享位提醒
  1. 01
    千咲先做链锯、解放和延奏，给队伍铺异常增益，再切夏空。
  2. 02
    夏空变奏后打到普攻第四段，接技能。回路满时打强化重击，开解放选绿色风蚀，马上延奏卡提希娅，让歌留在后台。
  3. 03
    卡提希娅变奏后接小形态普攻第二至四段、技能和下落，集齐并回收三把剑影。开解放变身，接第一段技能、空中重击和普攻第三至五段，再接第二段技能和普攻第三至五段。回路满后，尽量在目标仍有至少 5 层风蚀时放第二段解放。
  4. 04
    回千咲。开场一轮走顺后，再练视频里的双下落或夏空跳攻留场。你是 2 链，可以按相同链数的视频对照。

03
主力队湮灭

弗洛洛、坎特蕾拉、仇远

仇远与弗洛洛各有一处高收益补强

弗洛洛主C坎特蕾拉副C / 协奏仇远辅助 / 生存
共享位提醒
  1. 01
    开场先让弗洛洛召赫卡忒。由队友切入，打普攻第三段接强化招，再打技能接强化招并放声骸。按音符栏补到六枚，接强化重击和解放。你是 2 链，开场有预存音符时可以提前收。
  2. 02
    弗洛洛延奏给仇远。仇远变奏后接强化普攻第三、四段，蓄满剑意，开解放，打三段强化重击并使用声骸，满协奏切坎特蕾拉。
  3. 03
    坎特蕾拉变奏后接技能、解放，重击入强化状态，接强化技能、三段强化普攻和收尾技能。把主动声骸留在赫卡忒后台期间用，收尾技能命中后再延奏给弗洛洛。
  4. 04
    弗洛洛变奏回来触发强化变奏收场，再攒六音符。赫卡忒还在后台时先让队友打完各自的声骸动作，等协奏满再切回弗洛洛。
实战要点

先练成功两轮。第 3 队的仇远如果第二轮开不出大，先检查充能和重击是否打完，再追视频里的快切。

    回气动漂泊者。要练合轴时再把夏空跳攻或气动主的空中段插进长动画，先保持风蚀和两轮循环稳定。
